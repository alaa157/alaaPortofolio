06. Techniques

Test Design Methodologies

Industry-standard techniques applied during test case creation and exploratory testing.

Equivalence Partitioning

Dividing input data into valid and invalid partitions to reduce total test cases while maintaining total coverage.

Boundary Value Analysis

Testing at the extreme boundaries of input ranges where defects are statistically most likely to occur.

Decision Table Testing

Mapping complex business rules and multi-condition inputs to ensure every logical combination is verified.

State Transition Testing

Validating system behavior as it transitions between different operational states based on user actions.

Exploratory Testing

Simultaneous learning, test design, and execution to uncover unpredictable defects outside written scripts.

Negative Testing

Intentionally inputting invalid, out-of-range, or unexpected data to ensure robust system error handling.

Error Guessing

Leveraging QA experience to anticipate common developer mistakes and targeted application failure points.

Sanity & Smoke Testing

Quick health check executions to verify basic functionality before deeper testing passes commence.

07. Artifact Sample

Sample Bug Report Deliverable

An example of the actionable, precise defect documentation delivered to engineering teams.

DEFECT-2026-084

Checkout form accepts invalid email address format during guest purchase

Severity: Medium Status: Open
Environment Production-Staging v1.8 / Chrome 122 (macOS)
Module / Area E-Commerce Checkout / Billing Info

Preconditions:

User has added at least one item to cart and navigated to step 2 (Billing Information).

Steps to Reproduce:

  1. Enter valid full name and shipping address details.
  2. In the Email Address input field, enter: user@domain..com (double dot domain).
  3. Click the "Proceed to Payment" button.
Expected Behavior

Form validation blocks submission, highlights email field, and displays: "Please enter a valid email address."

Actual Behavior

Form submits successfully, proceeding to payment gateway with malformed email, preventing delivery receipt generation.
