STLC Process

A repeatable route from requirements to release

Testing is not just randomly clicking around. Here is my structured 6-stage Software Testing Life Cycle.

01 / REQ ANALYSIS

Requirements & Risk Review

Reviewing user stories, acceptance criteria, and edge conditions to catch ambiguities and specification gaps before code is written.

02 / TEST DESIGN

Test Strategy & Authoring

Creating comprehensive test scenarios, boundary value test cases, and negative test data matrices inside Jira / TestRail.

03 / EXECUTION

Execution & Exploratory QA

Executing test suites on target test environments, monitoring network payloads, and conducting unscripted exploratory testing.

04 / TRIAGE

Defect Logging & Triaging

Logging crystal-clear defect reports with steps, logs, expected vs actual outputs, and collaborating with developers on priority.

05 / REGRESSION

Retesting & Regression Sweeps

Verifying developer bug fixes, checking for unintended regressions across neighboring features, and updating test statuses.

06 / SIGN-OFF

Release Sign-Off & Report

Delivering a final QA Summary Report outlining test pass rates, residual risks, and providing confident release approval.
