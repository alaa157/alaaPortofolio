05 / QA deliverable

What a useful bug report looks like.

Clear defect documentation reduces back-and-forth and gives developers a reliable path from observation to reproduction.

SAMPLE BUG REPORTBUG-014

Checkout accepts an invalid postal code format.

MEDIUM · FUNCTIONAL
Chrome · Desktop · Test environment
1. Open checkout · 2. Enter valid cart details · 3. Enter an invalid postal-code format · 4. Submit the form
The form should reject the invalid value and explain the required format.
The form accepts the value and allows the checkout flow to continue.
Reproduction steps, affected field, expected/actual behavior and environment captured for developer investigation.
